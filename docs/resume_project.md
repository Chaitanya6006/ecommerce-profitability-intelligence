## 📄 Option 1: Full-Length Resume Entry (Recommended)

**E-Commerce Profitability Intelligence Platform**  
*Technologies: SQL (PostgreSQL/SQLite), Python (Pandas, SciPy, Matplotlib, Seaborn), Power BI (DAX, Power Query M), Git*

* Built a normalized star-schema data warehouse (51,290 transactions, 1,079 returns) in SQLite and PostgreSQL with surrogate keys, achieving $0.00 financial reconciliation between Python and SQL pipelines.
* Wrote advanced SQL analytics using CTEs, window functions (`RANK`, `DENSE_RANK`, `LAG`, `NTILE`), and RFM segmentation to identify 4,427 customer accounts generating -$773K in cumulative losses.
* Conducted statistical hypothesis testing using SciPy (Welch's t-test, Kruskal-Wallis, Games-Howell post-hoc, Chi-Square), proving discounts $>20\%$ cause product margins to drop into negative territory (-5% to -51%) while return rates remain independent of discount depth ($\chi^2 = 4.31, p = 0.116$).
* Designed a 5-page Power BI dashboard architecture with 25+ DAX measures, automated Power Query (M) scripts, and What-If parameter sensitivity modeling, estimating a potential operating profit recovery of ~$248.5K under a 20% promotional cap.
